# Mini MVC - E-Commerce

Application e-commerce en **PHP Vanilla** avec authentification, panier d'achat et gestion des commandes.

---

## ⚡ Installation rapide

### 1️⃣ Créer la base de données
```bash
mysql -u root -p ecommerce < ecommerce/database/schema.sql
```

### 2️⃣ Lancer le serveur
```bash
php -S localhost:8000 -t ecommerce\public
```

### 3️⃣ Accéder au site
Ouvrez : **http://localhost:8000**
